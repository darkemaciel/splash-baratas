Botão circular de 52px com um ícone de 26px, para ações do HUD e fechar painéis.

- Normal: fundo `cor-branco`, `sombra-p`. Hover: fundo `cor-creme`, `sombra-painel`, -8°. Pressionado: `cor-papel`, `sombra-pressionado`, deslocado 2px. Ativo (ex.: pausa aberta): `cor-creme` e `sombra-pressionado`. Desabilitado: borda tracejada, ícone `cor-cinza-quente`.
- Sempre passe `rotulo` (vira `aria-label`): "Pausar", "Fechar", "Som ligado".

Props: `icone` (nome do conjunto de Ícone), `rotulo`, `onClick`, `ativo`, `disabled`.
