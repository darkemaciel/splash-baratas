Pílula de 84 × 42px para ligar e desligar uma opção, com o estado escrito ("SIM" ou "NÃO").

Ligado: fundo `cor-limao`, "SIM" à esquerda e bolinha branca à direita. Desligado: fundo branco, bolinha `cor-papel` à esquerda e "NÃO" à direita. Props: `ligado` ou `ligadoInicial`, `rotulo`, `onChange`, `textoSim`, `textoNao`.
