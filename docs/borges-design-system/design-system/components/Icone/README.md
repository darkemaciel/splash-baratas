Ícones de traço de 3px em grade de 32 × 32, sem preenchimento, com pontas e junções redondas.

Conjunto: pausar, jogar, recomecar, menu, opcoes, musica, som, fechar, estrela, tempo, seta-anterior e seta-proxima (as setas usam traço de 4px e aparecem a 18px). A cor segue `currentColor`; use `cor-traco`, ou `cor-cinza-quente` quando desabilitado. Os corações e as estrelas preenchidos ficam dentro de HudVidas e CartaoResultado.

Props: `nome`, `tamanho` (padrão 26), `cor`.
